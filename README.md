# GameVault

GameVault es una aplicación web orientada a la gestión y organización de colecciones de videojuegos.

La aplicación permitirá a los usuarios consultar un catálogo de videojuegos, crear su propia biblioteca personal, guardar sus juegos favoritos, registrar su progreso y publicar valoraciones.

El proyecto se desarrollará utilizando Java y Spring Boot para el backend, MySQL para la base de datos y HTML, CSS y JavaScript para el frontend.
